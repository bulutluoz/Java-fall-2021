# Interview Preparation Package

This package contains comprehensive interview preparation materials for Java developers targeting FAANG and top-tier tech companies.

## Package Structure

### 1. `behavioral/`
Behavioral and situational interview questions with STAR method examples.

### 2. `phonescreening/`
Phone screening questions covering both technical concepts and initial behavioral assessment.

### 3. `whiteboard/`
Common whiteboard coding problems with detailed solutions and complexity analysis.

### 4. `faang/`
FAANG-specific interview patterns, questions, and coding challenges.

## How to Use This Package

1. **Start with Behavioral**: Review behavioral questions and prepare your STAR stories
2. **Phone Screening**: Practice explaining technical concepts clearly and concisely
3. **Whiteboard**: Solve coding problems, understand patterns, and practice complexity analysis
4. **FAANG Patterns**: Study company-specific patterns and problem types

## Interview Preparation Timeline

- **4-6 weeks before**: Start behavioral prep and review fundamentals
- **3-4 weeks before**: Daily whiteboard practice (2-3 problems)
- **2-3 weeks before**: Mock interviews and FAANG-specific patterns
- **1 week before**: Review mistakes, refine STAR stories, light practice
